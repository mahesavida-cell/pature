# **App Name**: InfoFlow

## Core Features:

- User Authentication: Secure user registration and login functionalities, allowing creators to manage their content and readers to access the platform.
- Media Post Creation & Editing: A user-friendly UI for authenticated creators to compose, format, publish, and edit news articles or media posts, utilizing the integrated Sanity.io headless CMS for content management and image uploads.
- News Feed & Content Display: A dynamic main feed showcasing all published articles and media posts retrieved from the Sanity.io CMS in an organized, minimalist layout for easy browsing.
- Individual Post Viewer: Dedicated pages for each article or post, providing a clean and distraction-free reading experience for full content and media sourced from Sanity.io.
- Basic Content Search & Filtering: Enabling users to quickly find relevant articles or media posts using keyword search or basic category filters.
- Headless CMS Integration: Integrate Sanity.io as the headless Content Management System for efficient and flexible content structuring, authoring, and delivery for all news articles and media posts.

## Style Guidelines:

- Light scheme, based on a cool, professional aesthetic for information clarity. Primary: a dark charcoal gray (#36454F) to convey professionalism. Background: a soft off-white (#F7F7F7) for spaciousness and readability. Accent: a medium gray (#888888) for subtle interactive elements and highlights.
- Utilizing two sans-serif fonts: 'Space Grotesk' for modern, clean headlines, and 'Inter' for highly legible body text. All textual elements, especially titles and headings, will primarily use Titlecase with minimal uppercase or large accents, in line with shadcn UI principles.
- Exclusively using Lucide Icons to maintain a crisp, minimalist, and unified visual style that aligns with modern digital interfaces.
- A minimalist, grid-based layout prioritizing clarity, ample whitespace, and intuitive content hierarchy. Designed to be fully responsive, ensuring optimal viewing across various devices, consistent with shadcn component styling.
- Subtle and purposeful animations handled by Framer Motion, enhancing user interactions and content transitions (e.g., hover effects, modal entries, page loads) without causing distraction, contributing to a fluid and modern user experience.
